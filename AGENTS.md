# AGENTS.md

`cr-tray` — один Rust-бинарник: трей KDE Plasma показывает расход CloseRouter,
курс ЦБ и непрочитанные письма. Окна настроек нет: флаги, env и JSON-конфиги.
Целевая среда — Linux/KDE Plasma (Wayland), системный трей.

## Быстрая проверка

```bash
cargo test
cargo clippy --all-targets
cargo run -- --demo --once
```

- `--demo` работает без сети и API-ключа, `--once` печатает снимок и выходит.
  Это же smoke-тест в release CI.
- Один тест: `cargo test parse_usd_rate` или
  `cargo test clock::tests::moscow_day_starts_at_21_utc`.
- Тесты не требуют сети: ответы API и ЦБ лежат в `tests/fixtures/` и вшиты
  через `include_str!`/`include_bytes!`. Отдельных интеграционных тестов нет —
  все `#[cfg(test)]` внутри модулей `src/`.
- Сам трей headless не проверить: нужен `plasmashell`,
  `org.kde.StatusNotifierWatcher` и свободный лок-файл. Для правок иконки:
  `cargo run -- --demo --dump-icons /tmp/cr-icons` и смотреть PPM-файлы.

## Структура

- Монолитный binary crate, без `lib.rs`; `src/main.rs` объявляет модули,
  вручную разбирает аргументы (без clap) и выбирает источник данных.
- `source::Source` — граница между данными и UI. `Demo` и `ApiSource`
  взаимозаменяемы, трей и `--once` видят только `Snapshot`. Меняя снимок,
  обновляйте оба источника.
- `api.rs` — `/v1/usage` и `/v1/credits`; `cbr.rs` — XML ЦБ (windows-1251)
  с дисковым кэшем; `mail.rs` — минимальный IMAP-клиент; `links.rs` — ссылки
  из конфига для пунктов меню; `clock.rs` — границы локального дня;
  `poll.rs` — фоновый опрос и backoff; `tray.rs` — меню/тултип ksni;
  `icon.rs` — собственная отрисовка иконки; `format.rs` — все
  пользовательские числовые строки.
- `links.json` читается в `main` и передаётся в `CrTray::new`; в меню пункты
  идут последними перед «Выход», подпись — только `name`, клик — `xdg-open
  url`. Записи без `name` или `url` отбрасываются на загрузке.

## Что легко сломать

- Все пользовательские строки — по-русски, десятичный разделитель — запятая.
  Тесты проверяют точный текст (`format.rs`, `icon.rs`, `source.rs`), поэтому
  при смене подписей правьте и тесты.
- `/v1/usage` трактует `YYYY-MM-DD` как UTC даже с параметром `timezone`.
  Границы дня считаются в `clock::day_bounds` и отправляются полными
  RFC3339-датами с `Z`; не заменяйте их на дату без времени.
- API отдаёт деньги в USD. Рубли = USD × `pay_rate`, где `pay_rate` —
  фиксированный `--pay-rate` либо курс ЦБ × `(1 + markup/100)` (по умолчанию
  12 %). Курс ЦБ сам по себе для расхода не использовать.
- Ошибка почты не должна переводить биллинг в `Status::Error`: показывается
  последнее удачное значение с пометкой «ошибка».
- Иконка ksni — ARGB32 в сетевом порядке байт (`A,R,G,B`), размеры 22/32/48 px,
  шрифт вшит. Не меняйте порядок каналов и размеры без правки тестов.
- Приоритет настроек: флаги → env → файлы в XDG. Ключ: `--api-key` →
  `CLOSEROUTER_API_KEY` → `~/.config/cr-tray/api_key`; почта по умолчанию —
  `~/.config/cr-tray/mail.json`. Минимальный интервал API — 5 с, почты — 60 с.
- Пароли почты хранятся только в `mail.json` (права 600), не передаются
  флагами и не логируются.
- `Cargo.lock` должен быть синхронизирован: release CI собирает `--locked` под
  `x86_64-unknown-linux-musl` и проверяет отсутствие динамических зависимостей.
  Тег `vX.Y.Z` обязан совпадать с версией в `Cargo.toml`; ручной запуск
  workflow даёт только artifact, без релиза.

## Стиль

UTF-8, LF, 4 пробела (`.editorconfig`). Комментарии, doc-комментарии и
README/CHANGELOG — на русском, как в существующих файлах. Пользовательская
документация и полный список флагов — в `README.md`; `docs/rust-toolchain.md`
описывает только установку Rust.
