# cr-tray

Расход CloseRouter за сегодня в системном трее KDE Plasma (Wayland).

Иконка показывает сумму за текущий день числом прямо на значке; тултип и меню —
расход в рублях и долларах, число запросов и токенов, баланс аккаунта, курс
списания CloseRouter и курс ЦБ. Данные обновляются в фоне раз в минуту.

Без окна настроек: всё задаётся флагами и переменными окружения.

## Как считается расход

* API CloseRouter отдаёт деньги в долларах (`cost`, `total_credits`).
* В рубли пересчитываем по **курсу списания** — тому, по которому CloseRouter
  реально списывает деньги при оплате. Публичного эндпоинта с ним нет, поэтому
  курс задаётся настройкой: по умолчанию **курс ЦБ + 12 %**.
* Курс ЦБ (с датой) показывается справочно, рядом.
* «Сегодня» — локальные сутки выбранной таймзоны; границы отправляются в API
  полными ISO-датами, потому что API понимает `YYYY-MM-DD` как UTC.

## Сборка

```bash
rustup default stable
cargo build --release
```

Бинарник: `target/release/cr-tray`. Внешних зависимостей нет — шрифт вшит,
TLS через rustls.

## Ключ API

Порядок поиска: `--api-key`, затем `CLOSEROUTER_API_KEY`, затем файл
`~/.config/cr-tray/api_key`. Файл нужен, если трей запускается не из терминала:

```bash
mkdir -p ~/.config/cr-tray
printf '%s' 'sk-...' > ~/.config/cr-tray/api_key
chmod 600 ~/.config/cr-tray/api_key
```

## Запуск

```bash
export CLOSEROUTER_API_KEY=sk-...
./target/release/cr-tray
```

Левый клик по иконке открывает меню: «Обновить», «Открыть дашборд», «Выход».

Один экземпляр на сессию: лок-файл `$XDG_RUNTIME_DIR/cr-tray.lock` не даёт
запустить второй трей.

## Флаги

```
--once                    напечатать снимок в stdout и выйти (без трея)
--api-key <KEY>           API-ключ, приоритетнее окружения
--timezone <TZ>           таймзона границ дня (по умолчанию системная)
--interval <SEC>          период опроса, секунды (по умолчанию 60)
--pay-rate <RUB>          курс списания, ₽ за $ (приоритетнее наценки)
--pay-markup <PCT>        наценка к курсу ЦБ (по умолчанию 12)
--warn-balance-rub <RUB>  порог жёлтой иконки (по умолчанию 50, 0 — выключить)
--demo                    фейковые данные, без сети и ключа
--demo-state ok|warn|error  фиксированное состояние иконки
--demo-cycle              переключать состояния каждые 5 секунд
--dump-icons <DIR>        сохранить пиксмапы иконок в PPM и выйти
-h, --help                справка
```

Окружение: `CLOSEROUTER_API_KEY`, `CR_PAY_RATE`, `CR_PAY_MARKUP`,
`CR_INTERVAL`, `CR_WARN_BALANCE_RUB`. Флаги приоритетнее.

## Иконка

| Состояние | Вид | Когда |
|---|---|---|
| норма | зелёный фон | всё в порядке |
| мало средств | жёлтый фон | баланс в рублях ниже `--warn-balance-rub` |
| ошибка обновления | красный фон, белое кольцо | API недоступен; показаны последние удачные цифры |

Подпись: `9,9` до 10 ₽, `226` до 10 000 ₽, дальше `12k` и `1,2M` — чтобы
число оставалось читаемым на 22 px.

## Проверка без трея

```bash
cr-tray --once
```

```
CloseRouter
  Сегодня:      29,23 ₽ ($0,3239)
  Запросы:      438 запросов · 75,3M токенов
  Баланс:       236,82 ₽ ($2,62)
  Курс оплаты:  90,22 ₽/$ (+12% к ЦБ)
  Курс ЦБ:      80,5573 (31.10.2026)
  Обновлено:    18:27
  Состояние:    норма
```

Код возврата `--once` — 1, если данные получить не удалось.

## Если что-то не работает

* **Иконки нет.** Проверьте, что `plasmashell` запущен и в D-Bus есть
  `org.kde.StatusNotifierWatcher`:
  `busctl --user list | grep -i StatusNotifier`.
* **«неверный API-ключ (401)».** Ключ отозван или скопирован с пробелом.
* **«не задан API-ключ».** Задайте `CLOSEROUTER_API_KEY` или файл ключа.
* **Курс ЦБ старый.** ЦБ недоступен — показывается последний сохранённый курс
  из `~/.cache/cr-tray/cbr.json`, дата рядом с курсом.
* **Второй экземпляр отказывается стартовать.** Это норма: один трей на
  сессию. Удалите `$XDG_RUNTIME_DIR/cr-tray.lock`, если процесс уже не жив.
