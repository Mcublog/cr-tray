# cr-tray

Расход CloseRouter за сегодня в системном трее KDE Plasma (Wayland).

Иконка показывает сумму за текущий день числом прямо на значке; тултип и меню —
расход в рублях и долларах, число запросов и токенов, баланс аккаунта, курс
списания CloseRouter, курс ЦБ и непрочитанные письма в настроенных ящиках.
Данные обновляются в фоне раз в минуту, почта — раз в пять минут.

Без окна настроек: всё задаётся флагами, переменными окружения и JSON-конфигом
почты.

История изменений — в [CHANGELOG.md](CHANGELOG.md).

## Как считается расход

* API CloseRouter отдаёт деньги в долларах (`cost`, `total_credits`).
* В рубли пересчитываем по **курсу списания** — тому, по которому CloseRouter
  реально списывает деньги при оплате. Публичного эндпоинта с ним нет, поэтому
  курс задаётся настройкой: по умолчанию **курс ЦБ + 12 %**.
* Курс ЦБ (с датой) показывается справочно, рядом.
* «Сегодня» — локальные сутки выбранной таймзоны; границы отправляются в API
  полными ISO-датами, потому что API понимает `YYYY-MM-DD` как UTC.

## Готовый бинарь

Статическая сборка (musl) собирается в GitHub Actions и лежит в релизах:
x86_64 Linux, без внешних зависимостей, работает на Ubuntu 22.04 и новее.

```bash
mkdir -p ~/.local/bin
curl -L -o ~/.local/bin/cr-tray \
  https://github.com/Mcublog/cr-tray/releases/latest/download/cr-tray-x86_64-unknown-linux-musl
chmod +x ~/.local/bin/cr-tray
cr-tray --demo --once     # проверка: печатает снимок на фейковых данных
```

Рядом с бинарём в релизе лежит `*.sha256` для проверки контрольной суммы.
Файл из artifact'а Actions (а не из релиза) приходит без бита исполнения —
после скачивания нужен `chmod +x`.

Релиз собирает `.github/workflows/release.yml`: по пушу тега `v*` (ручной
запуск даёт только artifact, без релиза). Версия в `Cargo.toml` должна
совпадать с тегом — `v0.2.0` для `version = "0.2.0"`, иначе сборка упадёт.

## Сборка

```bash
rustup default stable
cargo build --release
```

Бинарник: `target/release/cr-tray`. Внешних зависимостей нет — шрифт вшит,
TLS через rustls.

## Ключ API

Порядок поиска: `--api-key`, затем `CLOSEROUTER_API_KEY`, затем файл
`~/.config/cr-tray/api_key`. Файл нужен, если трей запускается не из терминала:

```bash
mkdir -p ~/.config/cr-tray
printf '%s' 'sk-...' > ~/.config/cr-tray/api_key
chmod 600 ~/.config/cr-tray/api_key
```

## Почта Mail.ru и Яндекса

Непрочитанные письма показываются строками вида `me@mail.ru: 3` в меню и
тултипе. Если хотя бы в одном ящике есть непрочитанные, на иконке появляется
маленький конверт, а сумма за сегодня немного уменьшается.

Публичного HTTP API для чтения почты у Mail.ru и Яндекса нет, поэтому трей
ходит по IMAP. Обычный пароль не подойдёт — нужен **пароль приложения**.

### Пароль приложения

* **Mail.ru:** Настройки → Все настройки → Безопасность → Пароли для внешних
  приложений → Создать → «Полный доступ к Почте».
* **Яндекс:** Почтовые программы → включить «С сервера imap.yandex.ru по
  протоколу IMAP» и «Пароли приложений и OAuth-токены», затем создать пароль
  на `passport.yandex.ru/security/app-passwords`.

### Конфиг

Файл `~/.config/cr-tray/mail.json`, права `600`:

```bash
mkdir -p ~/.config/cr-tray
cat > ~/.config/cr-tray/mail.json <<'EOF'
{
  "interval_sec": 300,
  "accounts": [
    {
      "name": "Работа",
      "login": "me@mail.ru",
      "password": "app-password",
      "url": "https://e.mail.ru/inbox/"
    },
    {
      "name": "Яндекс",
      "login": "me@yandex.ru",
      "password": "app-password"
    }
  ]
}
EOF
chmod 600 ~/.config/cr-tray/mail.json
```

* Ящиков может быть любое количество; строки в меню идут в порядке файла.
* `name` необязателен: без него показывается `login`.
* `interval_sec` — период опроса IMAP, по умолчанию 300 секунд, минимум 60.
* `host` — переопределить сервер. По умолчанию `imap.mail.ru` для
  `mail.ru`/`inbox.ru`/`list.ru`/`bk.ru` и `imap.yandex.ru` для
  `yandex.ru`/`ya.ru`/`narod.ru`. Для корпоративной почты на Яндекс 360
  (домен вида `company.ru`) укажите `"host": "imap.yandex.ru"` вручную.
* `url` — ссылка, которая открывается по клику на строку ящика в меню.
  По умолчанию `https://e.mail.ru/inbox/` для Mail.ru и
  `https://mail.yandex.ru/` для Яндекса.
* `folder` — папка, по умолчанию `INBOX`.

Файла нет — почта выключена, остальное работает как раньше. Если права файла
шире `600`, в журнал попадёт предупреждение. После правки конфига:
`systemctl --user restart cr-tray`.

Ошибка почты не красит иконку в красный и не влияет на данные CloseRouter:
в меню остаётся последнее удачное значение с пометкой «ошибка».

## Запуск

```bash
export CLOSEROUTER_API_KEY=sk-...
./target/release/cr-tray
```

Левый клик по иконке открывает меню: данные расхода, строки почты, «Обновить»,
«Открыть дашборд», «Выход». Клик по строке ящика открывает его веб-почту в
браузере (адрес задаётся полем `url`).

Один экземпляр на сессию: лок-файл `$XDG_RUNTIME_DIR/cr-tray.lock` не даёт
запустить второй трей.

## Автозапуск через systemd

Бинарник — в `~/.local/bin`, настройки — в `~/.config/cr-tray` (не в
`~/.local/bin`: это каталог для исполняемых файлов, а конфиги принято держать
в XDG-каталоге, и так их не затрёт переустановка бинарника).

```bash
# 1. бинарник
install -Dm755 target/release/cr-tray ~/.local/bin/cr-tray

# 2. ключ и настройки: файл с правами 600
mkdir -p ~/.config/cr-tray
printf '%s' 'sk-...' > ~/.config/cr-tray/api_key
chmod 600 ~/.config/cr-tray/api_key

# 3. юнит + запуск
./scripts/install-service.sh
```

Скрипт создаёт `~/.config/systemd/user/cr-tray.service` и
`~/.config/cr-tray/env` (шаблон), делает `daemon-reload` и
`enable --now`. Проверка и удаление:

```bash
./scripts/install-service.sh status
./scripts/install-service.sh uninstall
```

Юнит привязан к `plasma-workspace.target` (в Plasma 6 он активен в
systemd-сессии пользователя), поэтому поднимается вместе с рабочим столом и
перезапускается через 5 с, если трей упал на старте. Ключ сервис берёт из
`~/.config/cr-tray/api_key` или из `~/.config/cr-tray/env` — переменные твоего
shell в systemd не попадают.

Прочие настройки в `~/.config/cr-tray/env`, по одной строке `ИМЯ=значение`:

```
CLOSEROUTER_API_KEY=sk-...   # можно вместо api_key
CR_PAY_MARKUP=12
CR_INTERVAL=60
CR_WARN_BALANCE_RUB=50
# CR_PAY_RATE=90.22
# CR_MAIL_CONFIG=/home/user/.config/cr-tray/mail.json
# CR_MAIL_INTERVAL=300
```

После правки env: `systemctl --user restart cr-tray`. После обновления
бинарника — то же самое.

## Флаги

```
--once                    напечатать снимок в stdout и выйти (без трея)
--api-key <KEY>           API-ключ, приоритетнее окружения
--timezone <TZ>           таймзона границ дня (по умолчанию системная)
--interval <SEC>          период опроса, секунды (по умолчанию 60)
--pay-rate <RUB>          курс списания, ₽ за $ (приоритетнее наценки)
--pay-markup <PCT>        наценка к курсу ЦБ (по умолчанию 12)
--warn-balance-rub <RUB>  порог жёлтой иконки (по умолчанию 50, 0 — выключить)
--mail-config <PATH>      конфиг почты (по умолчанию ~/.config/cr-tray/mail.json)
--mail-interval <SEC>     период опроса IMAP в секундах (по умолчанию 300)
--no-mail                 не опрашивать почту
--demo                    фейковые данные, без сети и ключа
--demo-state ok|warn|error  фиксированное состояние иконки
--demo-cycle              переключать состояния каждые 5 секунд
--dump-icons <DIR>        сохранить пиксмапы иконок в PPM и выйти
-h, --help                справка
```

Окружение: `CLOSEROUTER_API_KEY`, `CR_PAY_RATE`, `CR_PAY_MARKUP`,
`CR_INTERVAL`, `CR_WARN_BALANCE_RUB`, `CR_MAIL_CONFIG`, `CR_MAIL_INTERVAL`.
Флаги приоритетнее.

## Иконка

| Состояние | Вид | Когда |
|---|---|---|
| норма | зелёный фон | всё в порядке |
| мало средств | жёлтый фон | баланс в рублях ниже `--warn-balance-rub` |
| ошибка обновления | красный фон, белое кольцо | API недоступен; показаны последние удачные цифры |

Подпись: `9,9` до 10 ₽, `226` до 10 000 ₽, дальше `12k` и `1,2M` — чтобы
число оставалось читаемым на 22 px.

Если есть непрочитанные письма, по центру сверху рисуется маленький
конверт, а сумма сдвигается вниз и немного уменьшается. Нет писем или почта не
настроена — иконка прежняя.

## Если что-то не работает

* **Иконки нет.** Проверьте, что `plasmashell` запущен и в D-Bus есть
  `org.kde.StatusNotifierWatcher`:
  `busctl --user list | grep -i StatusNotifier`.
* **«неверный API-ключ (401)».** Ключ отозван или скопирован с пробелом.
* **«не задан API-ключ».** Задайте `CLOSEROUTER_API_KEY` или файл ключа.
* **Курс ЦБ старый.** ЦБ недоступен — показывается последний сохранённый курс
  из `~/.cache/cr-tray/cbr.json`, дата рядом с курсом.
* **«неверный логин или пароль приложения».** Для IMAP нужен пароль
  приложения, а не обычный пароль от почты. У Яндекса также должен быть
  включён доступ по IMAP в настройках «Почтовые программы».
* **Почта не появилась в меню.** Проверьте, что `~/.config/cr-tray/mail.json`
  существует и в `accounts` есть хотя бы один ящик. Файл разбирается как JSON:
  лишняя запятая или комментарий — ошибка при старте.
* **Конверта нет, хотя письма есть.** Счётчик показывает только папку `INBOX`
  (или `folder` из конфига) и обновляется раз в 5 минут. Ошибку ящика видно в
  меню и `cr-tray --once`.
* **Второй экземпляр отказывается стартовать.** Это норма: один трей на
  сессию. Удалите `$XDG_RUNTIME_DIR/cr-tray.lock`, если процесс уже не жив.
* **Сервис перезапускается по кругу.** Смотрите
  `journalctl --user -u cr-tray -n 30`: чаще всего «не задан API-ключ» —
  значит ключ не попал в `~/.config/cr-tray/api_key` или `env`.
